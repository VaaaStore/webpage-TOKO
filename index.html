Cara Edit Produk & Deploy Ulang

Semua barang (tambah/ubah/hapus) diatur langsung di dalam file products.json, supaya perubahannya terstruktur dan halaman web terload sangat cepat tanpa lag.

1. Buka file products.json

Buka file products.json pakai text editor (Notepad, VS Code, dll). Setiap barang dibungkus dengan kurung kurawal { ... }.

2. Tambah barang baru

Copy salah satu blok { ... } milik barang yang sudah ada, tempel di bawahnya (pisahkan dengan koma), lalu ganti isinya. Pastikan id pakai angka unik.

3. Tambah foto produk

Di dalam blok barang, cari baris "image": "". Isi bagian dalam tanda kutip dengan link foto dari Postimages/Imgur.

4. Upload ulang ke GitHub Pages

Setelah disimpan, upload file products.json dan file HTML Anda ke repositori GitHub Anda.
